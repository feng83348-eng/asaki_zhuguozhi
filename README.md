# 诸国志 · 角色卡外链资源

这是从用户提供的诸国志 3.2／主世界书 V2.8 离线包整理的运行资源。保留原文件和目录结构，供角色卡浏览器通过 HTTPS 按需加载。

- `assets/portraits/`：人物立绘与缩略图。
- `assets/world/`：地图与场景 WebP。
- `sources/`：44 份原有逐字来源文本，沿用原出处和哈希标注。

本目录不是完整 Wiki 网站，也没有角色卡、MVU、EJS 执行程序。`sources/` 中出现的角色扮演指令仅为来源文本，不作为程序运行。

上传时保留解压后的目录结构。部署后的根 URL 应能够访问 `assets/portraits/xialuling.png` 等文件。把这个根 URL 填入角色卡阅读器的「图片设置」。

可以使用 GitHub Pages 根目录发布，或通过 `https://testingcf.jsdelivr.net/gh/OWNER/REPO@VERSION/` 引用公开仓库中的资源；请替换 OWNER、REPO、VERSION。不要填写 GitHub 文件查看页，不要上传只有 Git LFS 指针的资源。

包含原 Wiki 提供的素材与来源，人物／美术中的原文未载细节沿用其编辑补充标识。地图点位是示意，不是原文精确测绘。
